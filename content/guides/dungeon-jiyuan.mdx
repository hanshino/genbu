## 通關可以拿到什麼

挑戰<Mission id={18933}>極淵寒獄</Mission>，每層選擇「探索深處」或「一般探索」，最後遇到的王決定獎勵。修羅、瘋馬路線會接續同名的<Mission id={18934}>極淵寒獄</Mission>任務，仍是這一趟探索，不必另外進本。

**只領所走結局的一組獎勵，不是把整張表全部領走。** <Item id={24078}>大金元寶</Item>每個賣給商店約得五十萬兩銀。

五種箱子都有機會開出 **Lv200 碧空烈漠系列武器與盾牌，而且相同武器的機率相同**，不是超品才有武器。其他重點包括八星、九星、十星、突破、超越覺醒符，以及技能真解、思如湧泉。

較高品級主要差在**百萬官幣、聖龍裝備圖紙與極淵材料的分布或數量**，不是所有獎項都比較容易出。極淵靈物可煉化成聖龍防具；點上方各種寶箱的道具連結，可查看完整「開啟可能獲得」。

## 進本前先確認

到**極之淵找裏暗部探子（48，84）**。Lv200 以上組隊進入，**建議五人同行，每日一次**；想再次挑戰，可使用<Item id={24428}>重置令</Item>或<Item id={24487}>極淵密令</Item>重置次數。每日重置時刻以現場為準。

接取後拿到<Item id={32831}>極淵玉牌</Item>一個與<Item id={32832}>靈石</Item>七顆。**玉牌只有六十分鐘，失效就會被傳出**；不要因為任務仍顯示剩餘時間而拖延。

入口進第一層、四次換層，以及終王房進寶箱房，**每次換區扣一顆靈石，一輪共用六顆**。接關也可能多扣靈石，不要任意丟棄。

## 選路與靈符

**這裡是自己選一般或深處，不是隨機分邊。** 每層只要打倒自己房間的王，不必把分頁裡的候選王全部打一遍。全隊先講好要走哪條；由誰操作、選路是否同步，以現場為準。

打倒王後，走到**目前房間下側的傳點**開啟特殊機關。選深處時先取得對應靈符，**使用後確認狀態已生效，再選「探索深處」**；一般探索不用該靈符狀態。

<Warning>
**靈符放在背包不算使用。** 沒有對應狀態就闖深處，會受到致命禁咒傷害。靈符能否重領、效期多久，以現場為準。
</Warning>

迅捷、巨力、剛甲、銳眼靈符分別用來抵擋對應禁咒，並抵禦大部分僵化、降攻、卸冑、盲眼詛咒效果。依目前的王選符，不要只記「第幾層用哪張」。

### 快捷路線

以下各列是一條可選走法，括號依序列出四次換層的選項：

- **超品**：蟻獅 → 人偶 → 將軍 → 牡丹精 → 魔女（深處、深處、深處、深處）。
- **極品**：蟻獅 → 人偶 → 將軍 → 牡丹精 → 妖后（深處、深處、深處、一般）。
- **上品**：蟻獅 → 人偶 → 將軍 → 油鍋怪 → 蜘蛛精（深處、深處、一般、一般）。
- **凡品**：蟻獅 → 吃人花 → 牛魔人 → 狂獅 → 修羅（一般、一般、一般、深處）。
- **普通**：蟻獅 → 吃人花 → 牛魔人 → 狂獅 → 瘋馬（一般、一般、一般、一般）。

各王的防禦與護勁相同，**內力、外功都能分擔輸出**。表格的要求命中是大於閃躲；卸冑、中毒依抗性推算，可施加不代表一定成功。

## 斷線與接關

途中斷線，可回極之淵找**裏暗部探子**回到該關。先與隊友確認目前打到哪隻王、要選哪條路，再繼續行動。

**接關不會延長玉牌效期。** 回戰鬥房會再扣一顆靈石，留意剩餘數量；玉牌失效就不能繼續這趟探索，重新挑戰前要確認每日次數或先重置。
