## 先講重點

劍法只要顧兩個屬性：**技巧和外功**。

1. **先讓技巧撐到摸得到怪**：打不中，傷害再高都沒用。記得把冰心算進去，它會讓你少點很多技巧。
2. **剩下的點數全部給外功**：劍法招式的傷害只吃物攻，玄學、內力都不會加傷害，不用像匕首那樣煩惱怎麼分。
3. **主攻醉月劍法**：每秒傷害最高，命中率也比裂空劍法好撐。

所以劍法配點的重點只有一個問題：**技巧到底要點多少？** 這篇就是在回答這件事。

## 第一步：技巧撐到摸得到怪

技能不會重擊，技巧加的重擊對劍法招式沒有用。技巧唯一的用途是命中：

**命中 = 3 × 技巧 + 等級 + 50 + 裝備命中 + 冰心**

### 冰心：移花宮的命中 buff

冰心除了固定加命中，還會**依你的技巧再多加**：

**冰心加的命中 = 固定值 + 技巧 ÷ 係數（無條件捨去）**

| 技能                             | 學習等級 | 加的命中（第 1 級 → 練滿）  |
| -------------------------------- | -------- | --------------------------- |
| <Skill id={119}>冰心訣</Skill>   | 21～57   | 3 + 技巧÷19 → 21 + 技巧÷10  |
| <Skill id={354}>冰心真訣</Skill> | 69～88   | 30 + 技巧÷5 → 86 + 技巧÷2   |
| <Skill id={713}>冰心靈訣</Skill> | 98～117  | 100 + 技巧÷2 → 200 + 技巧÷2 |

冰心靈訣練滿是 200 + 技巧 ÷ 2，等於**每點技巧變成 3.5 點命中**，再白送 200 點。技巧 93 的時候，冰心靈訣一放就是 +246 命中。

冰心是放在自己身上的 buff，換裝時會跟著目前的技巧重算。

### 技能命中的校正

每招有自己的命中率，會把你的命中放大或縮小：

**要撐的命中 = 怪物閃躲 × 100 ÷ 技能命中率**

要注意劍法有幾招的命中率**低於 100%**：<Skill id={356}>斷空劍法</Skill>、<Skill id={715}>裂空劍法</Skill>只有 85%，<Skill id={716}>醉月劍法</Skill> 92%、<Skill id={714}>落英紛飛</Skill> 95%。也就是說，用裂空劍法打閃躲 850 的怪，命中要撐到 1000，比怪物閃躲還高。

### 前期：看練功怪的閃躲

練功時只要打得到練功點的怪就好。到[練功地圖](/training-spots?school=劍法)輸入等級、選劍法，每個練功點都會列出「需撐命中」，技能命中率已經算進去了，扣掉冰心加的量，就是技巧要撐的命中。

下表是打得穩同等級七成五的練功怪、不算裝備命中，用那個等級段命中率最低的招式算：

| 等級 | 怪物閃躲 | 要的命中 | 技巧（沒冰心） | 技巧（有冰心） |
| ---- | -------- | -------- | -------------- | -------------- |
| 50   | 164      | 179      | 27             | **21**         |
| 70   | 214      | 252      | 44             | **32**         |
| 90   | 252      | 297      | 53             | **21**         |
| 120  | 406      | 478      | 103            | **31**         |
| 160  | 486      | 572      | 121            | **47**         |
| 200  | 731      | 860      | 204            | **118**        |

有冰心的那欄是用該等級學得到的最高級冰心算的。可以看到 90 等學了冰心真訣以後，要的技巧一口氣少一半以上，省下來的點數都能給外功。

## 第二步：剩下的點數全給外功

技巧夠了，剩下的點數全部給外功。劍法招式的傷害是（物攻 + 劍的傷害）× 技能倍率，玄學、內力都不會加傷害。

外功點越多，每點加的物攻也越多（物攻是分階算的），沒有別的屬性要跟它搶，所以**不用找什麼最佳比例，技巧夠了就一直點外功**。

劍法在每個等級段都有三種招，命中率和傷害算法不一樣：

| 等級    | 單發                             | 多段                             | 機率                             |
| ------- | -------------------------------- | -------------------------------- | -------------------------------- |
| 9～68   | <Skill id={112}>星雲劍法</Skill> | <Skill id={111}>落英繽紛</Skill> | <Skill id={113}>落月</Skill>     |
| 69～97  | <Skill id={356}>斷空劍法</Skill> | <Skill id={355}>落英飛瓣</Skill> | <Skill id={357}>舞月劍法</Skill> |
| 98 以上 | <Skill id={715}>裂空劍法</Skill> | <Skill id={714}>落英紛飛</Skill> | <Skill id={716}>醉月劍法</Skill> |

98 等以後的三招（點卡片看各級數值）：

<SkillCards ids={[715, 714, 716]} />

- **單發**：一次打倍率，再加一點固定傷害。
- **多段**：連打好幾段，每段各扣一次怪物防禦。
- **機率**：有一定機率打出高倍率，沒中就是低倍率。

不管主攻哪招，都只吃物攻，配點方式一樣。差別在傷害怎麼算、多久能打一發、好不好打中。

## 主攻哪招

下表是三招練滿，打同等級怪物平均防禦的期望傷害。配點是根骨 30、技巧照第一步有冰心那欄、剩下全給外功，武器用該等級的劍（120 等<Item id={20195}>聖曦王劍</Item>、160 等<Item id={55001}>龍躍鳳鳴劍</Item>、200 等<Item id={55233}>碧空烈漠劍</Item>）：

| 等級 | 怪物防禦 | 裂空劍法（一發／每秒） | 落英紛飛（一發／每秒） | 醉月劍法（一發／每秒） |
| ---- | -------- | ---------------------- | ---------------------- | ---------------------- |
| 120  | 646      | 13,599／22,664         | **21,748**／21,748     | 15,383／**25,638**     |
| 160  | 1,052    | 16,888／28,147         | **26,312**／26,312     | 19,174／**31,957**     |
| 200  | 1,895    | 15,321／25,535         | **20,960**／20,960     | 17,473／**29,121**     |

每秒傷害是用間隔時間換算的：裂空劍法和醉月劍法 0.6 秒一發，落英紛飛 1 秒一發。

- **醉月劍法每秒最痛，建議主攻**：和裂空劍法一樣 0.6 秒一發，但七成機率打 2700%、三成打 1100%，平均 2220%，比裂空劍法的 1950% 加 200 還高。命中率 92% 也比裂空劍法的 85% 好撐。
- **落英紛飛一發最痛**：8 段加起來 3440%，命中率 95% 最好撐，但要 1 秒才能打一發，換算每秒反而最低。8 段各扣一次防禦，怪越硬越吃虧：200 等打防禦 2,800 左右的怪，一發就輸給裂空劍法了。
- **裂空劍法沒有贏醉月劍法的地方**：傷害較低、命中率又最差，只有真氣比較省（39 對 45）。

69～97 等也一樣：<Skill id={357}>舞月劍法</Skill>平均 1666%，比<Skill id={356}>斷空劍法</Skill>的 1400% 加 200 高，命中率也是 92% 對 85%。

主攻醉月劍法的話，技巧照 92% 去撐就好。第一步的練功怪表是用命中率最低的招式算的，所以主攻醉月劍法要的技巧會比表上再少一點。
