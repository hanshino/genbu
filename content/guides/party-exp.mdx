## 這篇在講什麼

前面幾篇一直強調「打怪一定要組隊，沒人也要開分身組平均」，但具體能多多少經驗，很多人其實不清楚原理。這邊引用巴哈網友**凱撒龍**在回覆裡的詳細解說（原文出處為留言區第 6 樓，感謝他願意花時間整理）。

<Verify>此算法為玩家凱撒龍於 2017 年整理，其本人回文中也提到「不說以前的經驗算法，來討論目前的」，代表經驗公式先前已經變過一次。遊戲經驗值機制屬於容易隨改版調整的內容，這份公式的正確性請務必用小數字實測驗證後再套用。</Verify>

## 關鍵結論先講

天佑之類的加倍、三倍、四倍，或官方活動的加倍效果，**不是直觀的乘法（X2 X3 X4）**，而是**額外多給一排經驗**（轉生加成也是同樣邏輯）。

三種組隊狀態的經驗公式：

- **沒有組隊**：原始經驗
- **一般組隊**：原始 + 1/4 原始 + 加倍
- **平均組隊**：原始 + 1/4 原始 + 原始/人數（看有幾個人在同一張地圖）+ 加倍

很明顯可以看出：**平均組隊 > 一般組隊 > 沒有組隊**

## 別被「人越多、自己倍率越低」騙了

從表格看，隨著同地圖人數變多，自己拿到的經驗倍率確實在下降（x2.25 → x1.75 → x1.58 → x1.50 → x1.45）。但這不代表人越多越虧，正確的看法是：

> 如果對方也在打怪，那就是「自己經驗 + 組隊經驗（上面表格中的加成部分）」乘以「人數（扣除自己）」

用實際數字驗證：

- **自己單獨平均組隊**：100 x 2.25 = 225
- **兩人一起平均組隊**：100 x 1.75（自己那份） + 100 x 0.75 x 1（分享給隊友那份）= 250，等於 x2.5
- **五人一起平均組隊**：100 x 1.45（自己那份） + 100 x 0.45 x 4（分享給隊友那份）= 325，等於 x3.25

## 結論：能湊人就湊到五人

<Tip>
如果地圖能容納下五個人，而且不會打到沒怪打，建議直接**平均組滿五人**，這是效益最高的組隊方式。沒有真人隊友的話，用分身組平均也適用同樣的邏輯。
</Tip>

補充一提，同地圖有另一玩家（例如夫妻檔）一起打怪，也會有額外經驗加成，雖然幅度不大，但也算是佐證「同地圖有人在打」確實有差。

<Verify>「夫妻同地圖打怪也有多經驗值」是另一位巴友在留言中補充的說法，未經凱撒龍本人的公式驗證，僅供參考。</Verify>

## 小結

1. 加倍、三倍、四倍不是乘法，是額外多加一整份經驗
2. 平均組隊永遠比一般組隊、沒組隊划算
3. 同地圖人數變多，自己的倍率會降低，但團隊總效益反而更高
4. 能湊到五人平均組隊，就是目前已知效益最高的打法
