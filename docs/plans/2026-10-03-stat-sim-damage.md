# 屬性模擬器：傷害試算

## 目標

讓玩家選一隻怪，看到自己目前配點**打牠每下多少**，以及「外功 / 內力等各多加 1 點，每下多幾點」。這是 `2026-10-02-stat-simulator.md` §3「傷害」那一條的第一步：把效益從「物攻 +80」換成「打某隻怪每下多 X」。

第一版只做**單下傷害 + 邊際效益**。期望值（乘重擊率）和 DPS（乘攻速）都不做，原因見「不在第一版」。

公式來源：tthol_data `scripts/damage_capture_investigation.md`（2026-10-02 起，封包逐下擷取，十四次實測）。

---

## 公式

```
k = K / (K + D)，K = 5 × 怪物等級 + 500
普攻 = ⌊k·B⌋ − ⌊D/2⌋
重擊 = ⌊2·k·B⌋ − ⌊D/2⌋        ← 乘法部分加倍，D/2 只扣一次，不是「普攻 × 2」
技能 = ⌊m·k·B⌋ − ⌊D/2⌋        ← m 見下表，多段技能每段各算一次
```

- **B**（攻擊值）和 **D**（防禦值）由武器類型決定，見下表。物攻、內勁直接用模擬器算出的面板值。
- **取整**：「乘完取 floor，再減 ⌊D/2⌋」是候選，只有一組資料點驗證過（空手、沒亂數：物攻 155 打吹箭客 Lv37 防 29，148 − 14 = 134、297 − 14 = 283 都中）。其他資料只驗證到 ±1。
- 武器傷害直接用裝備的 id 查 `items`：一般武器讀 `damage_min/max`，**拳套讀 `pdamage_min/max`**（龍躍鳳鳴手套 55004 的 damage 是 0/0、pdamage 是 1096..1114，跟實測一致）。
- **強化不改武器傷害區間**：劍 +17 用 DB 的 945..970 算，12 種怪都吻合，亂數寬度也剛好約 k × 25；倭刀 +5 用 DB 的 1168..1222 也吻合。角色檔不用新增欄位。
- **真解不改普攻**：倭刀（有真解）的普攻吻合。但真解的詞條都是技能類（技能倍率、傷害 +N 等），對技能的影響完全沒測過。所以武器帶真解時，技能結果要加註記。
- 輸出是**區間**：武器傷害取下限、上限各算一次。同一種怪的不同隻之間還會差幾點，UI 顯示區間就好。
- 卸冑（status 1136，param1 40）是把 D 乘 0.4 再進同一條公式。第一版不做狀態，但函式的 D 要留成參數，之後可以接。

### 武器類型 → B / D

| 武器（DB 類型） | B | D | 狀態 |
|---|---|---|---|
| 劍 SWORD、刀 BLADE、倭刀 GREAT_SWORD | 物攻 + damage | `npc.extra_def` | 已驗證（移花宮、羅煞刀、天外天） |
| 拳套 PUNCHER | 內勁 + pdamage | `npc.magic_def` | 已驗證（惡人谷；搗藥君 extra_def 96 / magic_def 126 分得出來） |
| 空手 | 物攻（沒有亂數） | `npc.extra_def` | 已驗證（吹箭客 134 / 283 精確吻合） |
| 匕首 STING、棍 ROD | 物攻 + damage | `npc.extra_def` | 推定（只有 damage 欄，合理但沒驗證） |
| 雙劍 HAMMER | 物攻 + damage | `npc.extra_def` | 推定（用的是劍的圖示） |
| 拂塵 WHISK、杖 STAFF、扇 CLAW、拳刃 BOXING | — | — | 尚未支援：有些兩欄都有值，不知道用哪一欄、打哪種防禦 |
| 手甲 BOW、暗器 HIDDEN_WEAPON（`RANGED_WEAPON_TYPES`） | — | — | 尚未支援：遠程物攻本來就不在第一版 |

DB 的類型名稱跟中文武器名對不太上：杖 = STAFF、扇 = CLAW、手甲（55006）= BOW、雙劍 = HAMMER。UI 一律顯示中文名。

**推定的武器照算**（2026-10-03 決定）：匕首、棍、雙劍照劍的公式算，結果旁邊標「推定，尚未實測」，之後實測不符再改。

tthol_data 有個沒驗證的猜測：pdamage > 0 就是內勁武器（內勁 + pdamage，打 magic_def），否則是物攻 + damage，打 extra_def；兩欄都有值的武器，也許要看技能決定用哪一種。第一版不採用這個猜測。

### 怪物等級範圍

K = 5·Lv + 500 是用 Lv22..101 的怪擬合的（Lv101 只有一個樣本）。資料裡的怪最高 Lv200。高於 101 的怪照樣能選、照樣算，但結果旁邊要註記「K 只驗證到 Lv101，高等怪物可能有誤差」，不隱藏。

## 邊際效益

- 實作：`computePanel(character, data)` 是純函式，所以邊際效益 = 複製角色 → 某個屬性 +1 → 重算面板 → 重算傷害 → 跟原本相減。引擎不用重構。
- 候選：六圍各 +1。
- 在這條公式下，**只有影響 B 的屬性會讓單下傷害變多**：拿劍時是外功（→ 物攻），拿拳套時是內力（→ 內勁）。根骨、技巧、身法、玄學會顯示 +0。這是對的，但看起來會像壞掉，所以 UI 要加一行說明：「技巧 / 玄學影響重擊率、身法影響攻速，第一版還沒算進來」。
- 毒舌亂神類（func_dmg 6）同時吃內勁和物攻，外功和內力都會有效益，會是少數兩項都非 0 的情況。

## UI

放在屬性模擬器裡，新增一個「傷害」區塊或分頁（跟 `panel-cards.tsx` 並列）：

1. **選怪**：combobox 搜 `npc` 裡 `is_monster = 1` 的怪，顯示名稱、等級、防禦 / 護勁。沒有現成元件可以直接用，照 `recipe-combobox.tsx` 的做法做一個。
2. **結果表**：普攻、重擊、角色已學且已驗證的主動技能，各一列，顯示傷害區間。未驗證的技能列出來，標「尚未支援」。
3. **邊際效益**：六圍各 +1 後普攻（或選定技能）每下多幾點。

伺服器端要多查 `npc`（等級、extra_def、magic_def）和 `magic` 的 func_dmg / p1..p3，照現有 stat-sim 的 data 載入方式加。

## 不在第一版

- **期望值**：要用重擊率。面板有「重擊」數值，但「數值 → 機率」怎麼換、超過 100 怎麼算（巴哈說等於 100）都沒實測。
- **DPS**：攻速表不完整，攻速值換成實際攻擊間隔的關係也還不知道。
- **命中 / 閃躲**：封包的類型 2 / 3 是閃躲還是拆招都還沒分辨，命中率公式沒有。
- **狀態**：卸冑、幻影分身（基數對身法的分階還沒確定）、各種增傷 buff。
- **怪打玩家**：玩家的防禦 / 護勁怎麼減傷還沒測。
- **遠程武器**、未驗證的武器類型和 func_dmg。

---

## 還沒決定

- **重擊率**：沒測過，面板重擊值跟重擊 % 的關係不知道。不影響第一版，做期望值之前要先補測。
- **邊際效益要以「每點」還是「每點數成本」計算**：加點成本會隨屬性值變（`nextCost(v)`），高屬性時 +1 點要花更多點數。第一版先用「每 +1 屬性」，比較直覺；之後做 CP 值時再換成「每點數成本」。
- **選怪的 UX**：要不要用地圖或練功點篩怪（`training-spots` 計畫有怪物和地圖的對應），還是純搜名稱。
- **門派覆蓋**：只實測過移花宮、惡人谷、天外天三個門派。其他門派的武器（例如法術系）多半要等 tthol_data 補測，第一版先依武器類型表判斷，不依門派。
- **K 的高等怪驗證**：tthol_data 待做第 1 項（Lv150 以上的怪），有結果再決定要不要拿掉註記。
- **重擊扣的是 D/2 還是 0.4·D**：tthol_data 待做第 2 項。差異在個位數到十位數，不影響第一版結論。
