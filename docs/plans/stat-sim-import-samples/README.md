# TTHOL1 匯入樣本（2026-10-03 實機讀取）

格式規格見 `../2026-10-03-stat-sim-import-format.md`。這裡的檔案由 tthol-memory 的原型匯出器（`export_proto.py`，尚未併入 tthol-memory）從兩個執行中的 client 讀出，**只讀不寫**。

| 檔案 | 角色 | 重點 |
|---|---|---|
| `止戰詩園-Lv190.{json,txt}` | 天外天（8）Lv190，四轉（推算總和 140） | 雙手刀 HAND_R、天御蒼龍甲 50444 +5 |
| `晨曦破空-Lv192.{json,txt}` | 移花宮（4）Lv192，四轉（推算總和 140） | 劍 +17 + 盾、天御蒼龍甲 50444 +0、**收藏 1151 Lv1 出現在 skills** |

- `.txt` 是 `TTHOL1.` 字串（約 1.1 KB），`.json` 是解碼後的內容，兩者是同一份資料（已做過 round-trip 驗證）。
- 讀取當下兩隻角色身上**沒有丹藥**：`panel.attributes − bare − 裝備（實例 + 強化）− 被動 magic_stats` 六項都是 0（tthol-memory probe 驗算）。匯入後 genbu 算出的六圍應該跟 `panel.attributes` 完全一樣，這可以當成第一個驗收條件。
- 兩隻都**不是** compat 佈局。

## 建議 genbu 驗證的項目

1. 解碼：`DecompressionStream("deflate-raw")` 能解開 `.txt`，結果跟 `.json` 一致。
2. `inferRebirthPoints` 兩隻都要得到 140、狀態 `ok`。
3. 裝備拆解：
   - 50444 天御蒼龍甲：DB 固定值是空的，兩格狂暴劫匪小真元強化 10641（防禦 +25 固定）。剩下的部分要拆成 4 條隨機素質；兩件都沒有根骨，雖然 `mod_count` 是 5–5。
   - 55001 龍躍鳳鳴劍 +17：`stats` 是實例數值，不含強化，強化要由 genbu 的 `enhancementsByPath` 自己加。
   - 有區間的插槽（例如 11142、10996）走規格第 5 步的分配規則。
   - **晨曦破空的 55001 是插槽和隨機素質撞同一屬性的實例**：`stats.str = 24`，兩格 11142 特外功赤魂石（外功 9–11 或 12），隨機素質又有外功 5–10。照規則，插槽先取 min 9+9，剩下的 6 給隨機素質，結果合法。另一種可能是 12+12、沒有抽到隨機外功。兩種拆法的面板結果相同。
   - 55012 龍躍鳳鳴盾：外功 7 來自插槽 10992 中外功青魂石（5–7）；命中 25、根骨 5 是隨機素質。
4. 拆完用 `computePanel` 跟 `panel` 對照，列出差值。可以預期的差值：經脈（v1 不計算）、負重殘差、拿武器時的攻速。
